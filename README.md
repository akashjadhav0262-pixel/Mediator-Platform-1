What it does:
A browser-based web application that connects clients (who need work done) with freelancers (who offer services). Everything works instantly—no login, no backend, no downloads.

How it works:

Clients post projects (title, description, budget)

Freelancers browse open projects and submit proposals

Clients review proposals and accept the best fit

Status updates from "Open" → "Assigned"

Data persists across browser sessions using localStorage

Key Features:
Role-based views (Client/Freelancer)
Project posting & proposal system  
Help & Contact modal
Responsive design (mobile-friendly)
No backend needed

Tech Stack:
HTML | CSS | JavaScript (no frameworks)

Why I built it:
To demonstrate building a fully functional interactive app using only front-end technologies, showing skills in:

DOM manipulation & event handling

State management without backend

User experience design

Modular, readable code

Demo Flow:
"Open browser → Choose role → Post/Browse projects → Submit/Review proposals → Accept project → Done!"
